# AI-PhD SKILL 之 人人都是 Sales

[← 返回目录 / Index](../../README.md) · 中文原文 · [English](4-We-Are-Sales-EN.md)

我越来越觉得，科研中的每个人都在做某种形式的【销售】。

你提出一个 idea，希望导师愿意支持；你邀请同学合作，希望对方愿意投入时间；你写论文，希望 reviewer 接受你的 claim；你做报告，希望听众理解并记住你的工作；你申请实习、项目或教职，希望对方相信你的能力和潜力。

这些场景都在完成同一件事：

【让别人理解你的价值，并愿意 buy in】

这里的 sales 并不意味着夸张包装。它更接近一种基本能力：把价值讲清楚，把证据摆出来，降低别人理解、相信和支持你的成本。

1、Idea 不会自己说话

很多人相信一句话：【是金子都会发光】。

但金子本身不会发光，只会反光。

一块金子首先要有真实价值，同时也需要被光照到、被人看到、被正确识别。如果它一直埋在地下，或者混在一堆石头里，大多数人没有能力，也没有义务主动把它挖出来。

科研工作也是这样。

一个好 idea、一篇好论文、一项扎实的结果，并不会自动获得关注。它需要清晰的 title 和 abstract，需要完整的故事，需要有效的报告，也需要适当的传播和 PR。

同一个工作，可以被描述成：

我们在某个 benchmark 上提升了 1.5%。

也可以被描述成：

现有方法在一类关键样本上存在系统性失败，我们定位了原因，并提出了一个低成本的解决方案。

两种表达可能对应同一组实验，但读者获得的信息完全不同。前一种只有结果，后一种包含问题、缺陷、洞察、方案和价值。

科研中的很多竞争，也发生在【如何定义和表达价值】这一层。

你的工作解决了什么问题？为什么这个问题值得关注？现有方法为什么不够？你的观察带来了什么新信息？别人为什么应该使用、引用或继续研究它？

如果这些问题没有讲清楚，读者就需要自己寻找答案。大多数人不会为一篇陌生工作投入这么多额外精力。

所以，一个很重要的原则是：

【不要把识别工作价值的任务全部交给别人】

2、不要提前替市场拒绝自己的 Idea

做科研时，一个常见心态是：

这个 idea 好像不够惊艳。
方法看起来有点简单。
提升幅度似乎不够大。
别人可能不会感兴趣。
大组也许早就做过了。

于是实验还没有充分验证，作者自己已经开始打退堂鼓。

谨慎当然重要，但过早自我否定会让很多潜在工作失去继续生长的机会。科研中的大多数 idea，在最初阶段都不完整。它们可能只是一个现象、一个猜测、一个小改动，或者一个模糊的问题意识。

Idea 的价值往往需要通过实验、分析和表达逐渐显现。

一个看起来普通的 idea，可能揭示稳定的失败模式；一个简单的方法，可能说明过去的方法过度复杂；一个不大的平均提升，可能集中发生在最重要的 hard cases 上；一个工程改动，可能显著降低真实部署成本。

所以，不要因为 idea 第一眼不够华丽，就提前替导师、reviewer 和整个社区作出拒绝决定。

【你的任务是把它验证清楚，并以最强、最诚实的形式呈现出来】

最终是否值得 buy in，可以交给市场判断。

3、科研也需要 PR

很多科研工作在完成论文之后，传播就停止了。作者默认论文上线、代码开源之后，社区自然会注意到它。

现实中，大家每天面对大量新论文。Attention 是稀缺资源。即使工作本身很好，缺少传播也可能让它长期处于无人知晓的状态。

所以，科研同样需要 PR。

PR 可以是一个清楚的论文标题和摘要，可以是一场讲得明白的报告，可以是一篇总结工作的帖子，也可以是主动联系相关研究者、开源易用的代码、制作直观的 demo，或者在合适的场合介绍自己的发现。

这些行为的目的很简单：

【让正确的人更容易看到、理解和使用你的工作】

好的 PR 不需要制造虚假热度，也不需要到处重复宣传。它更强调准确定位和有效触达。

你的工作和哪些研究者相关？
它解决了哪个社区正在关注的问题？
别人最应该记住哪一个结论？
什么形式最能展示它的价值？
读者看完之后，下一步可以做什么？

PR 的核心，是为有价值的内容建立一条更短的传播路径。

有些人对 PR 天然排斥，觉得主动介绍自己的工作显得功利。但如果你的研究确实有价值，清晰传播本身也是研究工作的一部分。它能帮助相关研究者更快发现结果，减少重复劳动，也可能带来新的讨论、引用和合作。

金子的纯度决定它有没有价值，光线和展示位置决定别人能不能看见它。

【研究质量决定价值上限，PR 决定价值能否被充分看见】

4、好的 Sales 需要理解对方

科研中的 sales，核心并非反复强调自己有多好。真正有效的销售，需要先理解对方关心什么。

和导师讨论 idea 时，对方可能关心研究价值、可行性和时间成本；邀请合作者时，对方可能关心问题是否有趣、分工是否清楚、合作是否可靠；面对 reviewer 时，对方关心 claim 是否成立、比较是否公平、证据是否充分；做学术报告时，听众关心这个问题和自己有什么关系，以及最后能够带走什么结论。

所以，同一个 idea 面向不同对象，需要调整表达重点。

【改变表达重点可以，改变事实不可以】

你可以针对听众选择最相关的切入点，也可以用更清晰的方式组织材料，但不能因为对方关心某件事，就制造一个证据无法支持的结论。

好的 sales 主要完成三件事：让对方快速理解问题，让对方看到明确价值，让对方相信你的证据。

缺少理解，别人听不懂；缺少价值，别人觉得没必要；缺少证据，别人觉得不可信。

一篇论文其实就是一套完整的销售材料。Title 和 Abstract 负责吸引正确的读者，Introduction 负责建立初步 buy-in，Related Work 负责确定位置，Method 负责解释方案，Experiments 负责提供证据，Ablation 和 Analysis 负责回答质疑，Limitations 负责划清边界，Rebuttal 则进一步降低 reviewer 的决策风险。

所以，写论文时不能只考虑【我做了什么】，还要考虑【读者为什么应该关心并相信它】。

5、简单 Idea 更需要讲清楚

很多人面对简单方法时，会下意识增加复杂度，担心方法看起来不够新。

但一个简单方法如果真的有效，简单本身就可能构成价值。

这时需要回答几个问题：为什么过去没有这样做？它解决了哪个被忽略的问题？它在什么条件下有效？结果是否稳定？简单性是否带来了效率、可解释性或可复现性优势？

简单方法更适合强调三个方面：

【问题洞察是否准确】
【解决方案是否必要】
【收益与成本是否划算】

复杂度无法自动兑换 novelty，简单也不意味着缺乏贡献。很多有影响力的工作，方法本身并不复杂，但它们识别了一个重要问题，并把事实讲得非常清楚。

好的 sales 能让别人看到：这个方法虽然简单，但它解决的问题重要，证据充分，使用成本低。

6、可以积极 PR，不能 Overclaim

Sales 和 PR 都有明确边界。

你可以选择最有说服力的角度，但 claim 必须由 evidence 支持。如果只在一个数据集上有效，就不要声称普遍有效；如果只测试了一个模型，就不要轻易声称 model-agnostic；如果提升主要来自更大的计算预算，就需要如实报告成本；如果方法只改善部分 case，就要说明适用范围；如果实验只能说明相关性，就不要直接写成因果结论。

标题和摘要把 claim 推得越高，实验就需要承担越重的举证责任。一旦证据接不住 claim，整个故事的可信度会迅速下降。

所以我更认可一种长期有效的表达方式：

【对价值积极，对证据克制】

你可以主动解释工作为什么重要，也应该尽可能展示它的最佳价值。但对于方法能力、适用范围和结论边界，需要保持准确。

如果一项工作缺少可靠结果，却依靠包装掩盖问题，就和销售假冒伪劣产品没有区别。选择性报告实验、隐藏失败结果、不公平比较、模糊数据来源、夸大个人贡献，以及用宏大叙事遮盖方法缺陷，都会持续消耗个人信用。

科研 sales 的底层资产是【可信度】。一次夸张表达也许能换来更多注意力，长期可靠的工作才能形成稳定的 reputation。

更健康的顺序是：

【先把产品做好，再把产品讲清楚，最后让合适的人看到它】

最后总结

大家其实都是 sales。

做科研时，我们不断向导师、合作者、reviewer、听众和整个社区介绍自己的 idea，希望他们理解价值，并愿意 buy in。

所以，不要因为 idea 看起来普通，就提前打退堂鼓。先认真验证它，找到它真正解决的问题，把最有价值的部分讲清楚，给出足够可信的证据，再通过合适的 PR 让相关的人看到它。

同时也要守住边界：不虚构价值，不隐藏代价，不把局部结论包装成普遍规律，不让表达跑到证据前面。

【大胆 sell，主动 PR，谨慎 claim】

是金子都会发光吗？

金子本身不会发光，只会反光。

研究质量决定你是不是金子，表达和传播决定光能不能照到你。
