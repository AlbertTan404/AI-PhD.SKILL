# AI-PhD SKILL 之：“我这个分数需要re吗”

[← 返回目录 / Index](../../README.md) · 中文原文 · [English](0.2-Should-I-Rebuttal-EN.md)

会议出分之后，总能看到很多交流贴，评论区里常见类似问题（以1–6分为例）：

- “2334是不是要撤稿了？”
- “3344可以re吗？”
- “2255怎么办…”

但其实，绝对分数本身并没有那么关键，更重要的是你在 AC batch 里的相对位置。最终给出推荐的是 AC，而不是分数本身。

其次，初始分数能反映的信息是有限的。很多审稿人在 rebuttal 阶段是有明显“涨分意愿”的。比如我自己，如果一篇论文整体不错，但初读时比较费劲、有不少困惑点，只要 rebuttal 能有效澄清，我是愿意从 3 提到 5，甚至 6 的。同样地，有些工作 idea 很好，但 writing 存在问题，我也会在 rebuttal 后提高评分。
所以关键不只是分数，而是审稿人的【态度】。这一点往往可以从 review comments 里读出来：

- 最理想的情况是 reviewer 【明确】写出 “I would raise my score if …”；
- 其次是 reviewer 明显处于困惑状态，【希望】某些点被解释清楚。哪怕你已经在论文里写了，reviewer 仍然感到 confused 也是很常见的，这本身就是 rebuttal 的空间。
- 相对来说，更困难的情况是 reviewer 只提一些【不痛不痒的问题】，然后保持沉默。这种情况下可操作空间确实有限。很多时候，运气在科研里占的比重不低，我们能做的只是尽量通过多次投稿来降低方差。

关于 rebuttal，本人一些不成熟的经验，仅供参考：

- rebuttal 不只是写给 reviewer，也是写给 AC 的；
- 可以争取认可，但没必要一味迎合；
- 不要被 reviewer 带偏，尤其是偏离 main contribution 的问题；
- 尽量精炼，直击核心。大家的时间都很有限，今年 ICML 的审稿负担尤其重。

最后，祝大家 rebuttal 顺利。
